# Exam timetabling with integer linear programming

B.Sc. (Statistics) project for STAT408 Operations Research and Mathematical Programming, University of
Chittagong, 2023. It schedules exams so that no student sits two at once and the exams each student
takes are spread as far apart as possible. The problem is solved as a binary integer program on two
instances of the Toronto benchmark, hec-s-92 and sta-f-83.

Report: [`report/MP_Project_Report.pdf`](report/MP_Project_Report.pdf)

## Results

- Three formulations: compact, pairwise and a strengthened model with clique constraints. Solved with
  HiGHS and CBC.
- On sub-instances, the strengthened model with HiGHS proves the optimum fastest: 31 s for 10 exams,
  against 53 s for the compact model. At 15 exams both reach the 120 s limit.
- On the full instances the linear relaxation bound is too weak to prove optimality, so simulated annealing
  with Kempe-chain moves and fix-and-optimise find the timetables.
- Best cost on hec-s-92 is 10.19, 1.6% above the best published 10.03. On sta-f-83 it is 157.03, equal to the
  best published value.

## Setup

Python 3.11 and the CBC solver (`brew install cbc` on macOS, or your package manager on Linux).

```
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run_all.sh
```

`run_all.sh` reruns E1, runs any experiment whose result file in `outputs/runs/` is missing, and rebuilds
every table, figure and timetable in `outputs/`. With the saved runs this takes under a minute. If you delete
`outputs/runs/`, every experiment reruns, which takes about an hour on a multi-core machine.

## Your own department

Fill `data/department_template.csv` with one row per student and exam (`student_id,exam_code`).
The example below runs from `src/` on the synthetic file, which has the same columns.

```python
import data, model, heuristic
inst = data.from_csv("../data/synthetic_department.csv", periods=12)
start, _ = heuristic.initial(inst, inst.periods)
tt, total, _ = heuristic.anneal(inst.matrix(), inst.periods, start, seconds=60, seed=0)
res, exact = model.solve(model.build_compact(inst, inst.periods, strong=True), "highs", time_limit=300)
```

Room capacities are not modelled.
